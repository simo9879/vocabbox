# Pip model source

The owner-supplied source archive is kept under ignored `.local/archive/bird-authoring/Yellow_Chick/`, outside Git. It contains the three baked FBX clips and color atlas used to rebuild Pip's game-ready GLB, along with unused Maya scenes, alternate animations, meshes, renders, and texture maps. The artist's `Read Before Use/Text.txt` says the baked FBXs need no mGear plugin, use 24 FPS, and may be used or edited for games; do not share or resell the source model separately.

Run `python3 tools/build_yellow_chick.py` from the repository root to regenerate `vocab-box/models/YellowChick_animated.glb`. The builder uses Godot's FBX importer, attaches the supplied color texture, keeps the skinned chick, and exports Fly, Idle, and Talk. Fly uses the source's wing cycle at frames 41–65 with a short blend across the seam, skipping the idle start and end. Talk combines that wing cycle with Feed's beak motion from 2.75–3.75 seconds. Fly root translation is omitted so `bird.gd` owns Pip's height beside the player. The FBXs include stray keys through 9.33 seconds; the builder removes keys outside each intended clip range. Idle remains in the GLB as a source clip but is not used by Pip's hovering behavior.
