VOCAB BOX — Linux x86_64 portable prototype
Run ./play.sh (or launch it from a terminal).
WASD/arrows move; mouse looks; E interacts; Escape pauses; H asks Pip; R replays Pip.
Choose answers with the mouse. Triangle buttons read choices aloud.

No Godot installation, network, microphone or speech engine is needed.
This portable bundle uses the installed Godot 4.7.2 executable as its runtime,
plus an exported PCK. It is larger than a release-template export because
release templates were not installed on the development host.
Requires a Linux desktop with working OpenGL 3.3/GLES3 graphics and audio.
See GODOT-LICENSES.txt for engine and bundled third-party notices.
Best stars and preferences are saved under Godot's user-data directory.
