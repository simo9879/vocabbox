# Bundled audio generation

The manifest contains 37 spoken lines. The 22 Pip-only lines use ElevenLabs voice ID `pFZP5JQG7iQjIQuC4Bku` and model `eleven_v4`; six answer phrases also have a Pip version for hints and practice. The six NPC lines use owner-supplied recordings of Alex, Sam, and Jo (27 October 2026); the nine answer-choice previews still use their original eSpeak NG WAVs. The lesson's `lines`, `hints`, encounters, and choices determine which speaker owns each line.

From the repository root, `python3 tools/generate_voice_audio.py` assembles the current mix from existing local files and makes **no API requests**. Pip audio is staged under ignored `.local/`; the six shared Pip phrase versions are installed under `vocab-box/audio/pip/`. Non-Pip lines restore their newest authored recording: the NPC clips in `backups/audio-npc-2026-10-27/` when the line has one, otherwise the eSpeak backup. Each filename is SHA-256(UTF-8 spoken text) + `.wav`, matching the lesson's resource paths. If a new Pip line requires synthesis, pass `--generate-missing` explicitly; the script then reads `ELEVENLABS_API_KEY` from the process or ignored root `.env` and requests 24 kHz mono PCM. This uses ElevenLabs credits. `--limit 1` processes one staged line without replacing active audio. If lesson wording changes, update the manifest and rebuild before packaging so subtitles and voices match.

All 37 original eSpeak NG clips, their manifest, and their generator are preserved in `backups/audio-espeak-2026-10-24/`. The six NPC recordings keep their untouched MP3 sources and normalized WAVs in `backups/audio-npc-2026-10-27/`; see that folder's README for the line mapping and conversion command. To regenerate only the deterministic city/shop ambience, footsteps and interaction tones, run `python3 tools/generate_audio.py`; this command leaves voice clips alone.

After changing audio, import it with `godot --headless --path vocab-box --editor --import --quit` (or the installed Godot executable). The game plays bundled WAV resources without a speech service at runtime. Spoken-answer reviews use the separate live ElevenLabs TTS path. Voice playback uses one player; new speech replaces previous speech and replay reuses that player. Choice playback is explicit. Voice, Music (ambient beds), and Effects have independent audio buses.
